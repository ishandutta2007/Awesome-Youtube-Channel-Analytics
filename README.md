## Top YouTube Channel Analytics Tools Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Channel Intelligence, Competitor Research & Performance Tracking*

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **YouTube Channel Analytics**. These tools help creators, agencies, and brands research competitors, discover outlier videos, track channel growth, analyze audience behavior, and identify content opportunities to grow their YouTube presence.



**Examples** include vidIQ, TubeBuddy, Social Blade, Tubular Labs, Metricool, ViewStats, NoxInfluencer, HypeAuditor, ThoughtMetrics, and ChannelMeter (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom analytics pipelines, and transparent data collection — ideal for developers building analytics tools, privacy-conscious creators, and teams avoiding subscription fees.

## SaaS/Hosted Platforms



- **[vidIQ](https://vidiq.com/)**  

  YouTube analytics and growth platform with keyword research, AI-generated daily ideas, competitor tracking, outlier detection, and channel audits. Free tier available with basic features; Pro and Boost tiers add deeper analytics .



- **[TubeBuddy](https://www.tubebuddy.com/)**  

  Browser extension and app suite for YouTube creators with A/B testing, thumbnail analyzer, SEO tools, bulk editing, and channel optimization features. Free tier with paid upgrades .



- **[Social Blade](https://socialblade.com/)**  

  Statistics tracking website for YouTube, Twitch, Instagram, and TikTok. Provides historical growth charts, subscriber comparisons, estimated earnings ranges, and SB Rank grades. Free with optional premium subscriptions .



- **[Tubular Labs](https://tubularlabs.com/)**  

  Enterprise social video intelligence platform covering 11 billion+ videos across platforms. Provides audience behavior insights, content strategy intelligence, influencer identification, and ad sales benchmarking for media companies and brands .



- **[Metricool](https://metricool.com/)**  

  Social media management and analytics tool supporting YouTube, Instagram, TikTok, and more. Features scheduling, unified inbox, competitor analysis, report generation, and Looker Studio integration for custom dashboards .



- **[ViewStats](https://www.viewstats.com/)**  

  YouTube analytics platform co-founded by MrBeast. Features outlier video discovery, competitor tracking, thumbnail search, trend alerts, and research collections. Pro tier at $49.99/month; Business tier starts at $249/month .



- **[NoxInfluencer](https://www.noxinfluencer.com/)**  

  Influencer marketing software with 100 million+ influencer database covering YouTube, TikTok, and Instagram. Provides channel analytics, audience insights, brand deal tracking, and campaign management tools .



- **[HypeAuditor](https://hypeauditor.com/)**  

  AI-powered influencer marketing platform with fraud detection, audience quality analysis, influencer discovery, and campaign tracking. Covers YouTube, Instagram, and TikTok with analytical reports and account comparisons .



- **[ThoughtMetrics](https://www.thoughtmetrics.com/)**  

  YouTube analytics and channel intelligence platform for creators and agencies.



- **[ChannelMeter](https://www.channelmeter.com/)**  

  YouTube analytics and creator management platform for networks and agencies.



## Open-Source GitHub Projects



- **[youtube-analytics-dashboard](https://github.com/harsha151/youtube-analytics-dashboard)**  

  Flask-based dashboard for YouTube video and channel analytics with SQL backend. Features topic search, top-viewed video retrieval via YouTube Data API, pagination, admin/user views, and timestamp tracking .



- **[Shorts_Tracker](https://github.com/svllvsxprod/Shorts_Tracker)**  

  FastAPI web app for public short-video channel analytics across YouTube, TikTok, and Instagram. Uses `yt-dlp` for data collection without OAuth or API keys. Features dashboard with charts, per-channel metrics (total/average/median views), delta tracking, CSV export, and Telegram authentication. SQLite backend with Docker deployment .



- **[ytsh — YouTube Intelligence Shell](https://pypi.org/project/ytsh/)**  

  CLI tool for pulling YouTube channel, video, and analytics data into local SQLite storage. Supports OAuth for Analytics API queries, channel spying with outlier detection, and shell completion. Query data with SQL after collection .



- **[Youtube-Dashboard (RunnyEgg)](https://github.com/RunnyEgg/Youtube-Dashboard)**  

  Python-based channel performance dashboard using YouTube Data API v3, Pandas, and Power BI. Features lifetime stats, view metrics over time, top 5 videos by likes, and engagement charts .



- **[YouTube Analytics Tool (devtayyabsajjad)](https://github.com/devtayyabsajjad/YouTube-Analytics-Tool)**  

  Frontend-only analytics tool for searching YouTube channels by name, URL, or handle. Displays subscriber count, video count, lifetime views, channel creation date, and estimated revenue based on RPM rates. Uses Chart.js for visualization .



- **[YouTube Dashboard (StamTheo28)](https://github.com/StamTheo28/youtube-dashboard)**  

  Django-based dashboard for YouTube comment analytics with sentiment analysis. Analyzes top 100 popular comments per video, provides sentiment breakdown, sortable data tables, CSV export, and visualizations .



- **[youtube-marketing-skills](https://github.com/adityaarsharma/youtube-marketing-skills)**  

  Open-source agent-agnostic YouTube growth toolkit with 21 AI commands and live channel MCP. Works with Claude Code, Cursor, Codex, and any MCP client. Features competitor gap analysis, keyword ideation, SEO optimization, and analytics. Positions as free vidIQ/TubeBuddy alternative .



- **[YouTube Channel Performance Dashboard (SuNiL-Chau)](https://github.com/SuNiL-Chau/Youtube-Dashboard)**  

  Simple dashboard displaying channel subscriber count, total views, and video count. Search by channel name or URL. Express.js backend with YouTube API integration .



- **[OpenClaw YouTube Analyst Skills](https://github.com/dmmdea/OpenClaw-Youtube-Analyst-Skills)**  

  Comprehensive MCP server setup for YouTube analytics with OAuth flow, Google Ads API integration, and quota management. Enables AI agents to query channel performance and ad spend data programmatically .



### Additional Strong Open-Source Options



- **[PlayerSells Open Data](https://github.com/playersells/open-data)** — CC BY 4.0 licensed aggregate measurements of YouTube, TikTok, X, Telegram, and Twitch. Includes follower percentiles, reach benchmarks, and engagement rates. No personal data, suitable for research and benchmarking .

- **GitHub Topic: youtube-analysis** — 20+ public repositories including NovaTube (AI-powered video analysis), YouTube Analytics Bot (Discord integration), and YouTube Discussion Tree (comment thread analysis) .

- **GitHub Topic: vidiq-alternative** — 5 public repositories including free no-login Chrome extension with outlier scores, views-per-hour, and revenue estimates backed by Cloudflare Workers .



**Frameworks for building custom systems**: Combine **ytsh** for CLI-based data collection, **Shorts_Tracker** for multi-platform short-video analytics, **youtube-marketing-skills** for AI-powered growth workflows, and **Metabase + SQLite** for custom dashboards to build a complete self-hosted YouTube analytics stack.
